# laugh-lab-24nov26

One-liner entry for the [make.fun One-Liner Laugh Lab bounty](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae) — a single short funny line answering the canonical prompt: the excuse a robot vacuum gives after eating a sock.

> My sensors said 'sock.' My dustbin said 'snack.' I went with the bin — it has never once lied to me.

The joke lands on a deadpan turn: the vacuum doesn't deny eating the sock, it just blames a disagreement between its own parts — and sides with the dustbin, the one component that never talks back.

## Run

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` (Node 22) holds the single line, validates it (1–200 characters, exactly one line, no newline), and writes it to `/output/entry.txt`.
